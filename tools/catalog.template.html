Three decades of OS-9/68K community software, gathered and made to run again. The disk’s own index is alphabetical, which is no use when you do not yet know what you are looking for. Open a category, or click any program to see what it needs and where it came from.

keep
Tick programs with + (or the space bar) to build a keep command you can paste at an OS-9 shell — see DOC/README-KEEP.

Sample output on a program’s card was photographed from that program running on the disk image — keystrokes into os9exec’s console, and the terminal stream rendered into the grid a vt100 would have shown. Nothing is mocked up, and where a program failed, its failure is what you see.

★ needs Microware’s cio — see DOC/README-CIO. Built from DOC/INDEX, DOC/ORIGINS, DOC/DEPENDS, the EFFO info_ files and the tree itself, so it cannot drift from what ships.
