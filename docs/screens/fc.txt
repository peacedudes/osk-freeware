/dd/CMDS/fc -?
Syntax:   fc [<file>]
Function: Takes first 350,000 bytes of a file or stdin
          and puts in one file and puts remaining bytes
          in another file for easily putting large files
          on 360k media.
Options:  none

$ ksh -c "cd /dd/tmp/ENC; /dd/CMDS/fc fc.txt"
Oops! File was already less than 350,000 bytes!
That's ok. Now you have two copies of the same
file.
$ ls -l /dd/tmp/ENC/fc.txt /dd/tmp/ENC/fc.txt_1
-rw-rw-rw-   1 0        0             242 Sep  3 07:02 /dd/tmp/ENC/fc.txt
-rw-------   1 0        0             242 Sep  3 07:02 /dd/tmp/ENC/fc.txt_1
