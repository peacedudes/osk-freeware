$ watch -?
Syntax: watch [<opts>] <device> [<opts>]
Function: watches the device for an incoming call
Options:
     -t=<time>    The time to keep to mmon stay on line (in min)
     -c=<cmd>     The command to execute by an incoming call
     -d           No device as argument given
     -d=<dev>     Starts the program on this device
     -m=<mtch>    The string <mtch> is the RING of the modem
     -b=<time>    Between two rings, there may pass maximum of <time> secs.
     -l=<logfile> Write a logfile to <logfile>
