$ rndir -?

Syntax: rndir [<opt>]
Version:  V1.0  13.02.1990
Function: rename directory names in big/small characters
Options:
     -?   show valid options
     -d   temp-files allways on current working directory !
     -h   help user
     -l   rename directories in small characters
     -n   don't erase temp-files after completition of work
     -q   quiet mode [no prints to terminal screen]
