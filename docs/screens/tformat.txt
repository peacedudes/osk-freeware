PVIC 1.0a =========
PVIC is a Portable VI Clone derived from STEVIE  3.69B.  It
has been written in Kernighan and Ritchie C, so it compiles
on both old and modern C compilers.
The  original  STEVIE  3.69B  I  got was written for MS-DOS
systems, and did contain many non portable things like BIOS
calls. I  have  removed  everything  from  STEVIE  3.69B  I
considered non-portable, and I did rewrite the I/O. I added
code  to  read  termcap  files.  I  gave many variables and
functions from the original STEVIE 3.69B more understandable
names.
