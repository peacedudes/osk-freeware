 uuxqt: process incoming queued UUCP traffic

 Usage:  uuxqt [opts]  <sys> [<sys>...]  [opts]

      <sys>   -process work for <sys>.  If <sys> name is 'ALL', all systems in
                 the Systems file are processed

 opts:  -xN   -set debug level to N.  0 = OFF (default), 9 = highest
        -q    -work quietly (no messages to the screen)
