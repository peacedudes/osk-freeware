  Costs: it needs `cio', which ships here by Microware's permission and
  which your own system may or may not carry.  At start-up os9exec prints
  four `F$SetSys: unimplemented 03D8' lines; they are the emulator's
  noise, not an error.


gshell and mshell -- menus
--------------------------

  `gshell' draws a full-screen file browser: a lettered list of the
  current directory, `+' and `-' to page, `.' to change directory, a
  letter to run a file and its lower-case twin to run it with parameters.
  `assembler', `compiler' and `editor' on this disk are the same engine
  pointed at one job each.  Help text in DOC/gshell.

  `mshell' reads a menu file named on its command line, and says
  `Could not open <name> (menufile)' without one.

  Both want TERM set.  Take one to hand somebody a machine that runs four
  things and nothing else, not to type at.
