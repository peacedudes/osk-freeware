$ argproc_demo readme
arg=readme, b=0, c=0, sGiven=0, s=this is a test, x=32, pi=3.144500
$ argproc_demo -x99 -sHello readme
arg=readme, b=0, c=0, sGiven=1, s=Hello, x=99, pi=3.144500
$ argproc_demo -help
argproc_demo: Usage: argproc_demo file ...
Demonstration program for argproc().  Note that no spaces are allowed
between a switch and its arguments (i.e. -x3 is okay, -x 3 is not allowed).
Options:
    -help    Print this message
    -b       Set b_bool TRUE
    -c       Set c_bool TRUE
    -sSTRING Set string s  [default: this is a test]
    -xINT    Set integer x [default: 32]
    -piFLOAT Set double pi [default: 3.144500]
