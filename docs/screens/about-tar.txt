$ about virmf
 virmf          the real MetaFont engine -- generates fonts from .mf sources

  for        TEXT TOOLS -- TeX
  how        Metafont. `virmf '&cmbase' '\scrollmode; \mode:=epsonlo;
             \input cmr10; \end'' renders all 128 characters of cmr10. THE
             JOB NAME COMES FROM THE COMMAND LINE: the same line fed on
             standard input renders the same font and calls it `mfput'.
