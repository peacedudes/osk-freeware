$ loadmem -?
Syntax   : LOADMEM <destinati address> <upper limit address> <path>
Function : loads file into memory at specified address
Notes    : - You must be super user
           - specify addresses in hex
$ savemem -?
Syntax   : SAVEMEM <from address> <to address> <path>
Function : saves memory block to file
Notes    : - You must be super user
           - specify addresses in hex
$ snap -?
syntax: snap {opt} [<file>] {opt}
function: write terminal screen snapshot to <file> (default "polaroid")
options:
        -s[=]<num>  starting line number
        -e[=]<num>  ending line number
        -l          list known terminal types (TERM)
        -n                      remove last character of long (80-char) lines
