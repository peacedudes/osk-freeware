|  C               -       Copy file                                           |
|                          The currently hightlighted  file  will be copied to |

|  T               -       Tag a file                                          |
|                          Just  colours  (tags)   the  currently  highlighted |
|                          file, or, if already will set it back to the normal |
|                          untagged state.  Used for multi-file  operations in |
|                          the Copy, Delete, Move and Attr commands.           |
|                                                                              |
|  L               -       List file                                           |
|                          Lists the currently  highlighted file to the screen |
|                          in nineteen  line  pages,  waiting  for  a keypress |
|                          between  screens.  Pressing  'Q' or ESC quits  this |
|                          function.  If the file  is an archive, with an ext- |
|                          ension of  .lzh, .lha, .zoo, .ar, .zip, or .gz  its |
|                          contents will be listed.                            |
|                                                                              |
|  U               -       Unarchive a file.                                   |
|                          Only LZH or LHA archives are supported as yet.      |
|                          Pressing  ESC  aborts this function. Press ENTER to |
|                          unarchive into the current directory.               |
|                          Requires Mike Haaland's LHA utility.                |
