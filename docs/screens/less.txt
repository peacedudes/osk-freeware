HOW TO RUN THIS DISK
====================

os9exec is the kernel.  You point it at a disk with OS9DISK and name a
program to run; that disk becomes /dd, OS-9's root and home, and the program
runs.  There is no OS9Boot file here and none is needed -- os9exec supplies
the kernel a boot file would otherwise load.  Mount this collection as /dd,
the recommended arrangement below, and it runs on its own.

Most of the programs in CMDS and CMDS/GAMES need nothing but this disk.

------------------------------------------------------
Trying things before you fetch cio
------------------------------------------------------

If you run OS-9 you have cio, csl and math -- but the SDK may be on a shelf
rather than to hand.  This is what works in the meantime, so you can look
around the disk straight away:

    a shell        sh, or bash
    list a dir     ls
    read a file    cat, or less
    copy a file    cat one > two
