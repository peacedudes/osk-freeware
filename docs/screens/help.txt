DINFO
-----

DINFO - Display disk information

Important:    This   program    is  public    domain  and  may  be  used  and
              distributed freely as long as the "Distribution_Rules" are  met
              (see subtopic in this help file).

Syntax:       DINFO [<options>] {<device name> [<options>]}

              Note: The syntax is identical to that of the OS9  free  utility
              (except for the additional options -l -e -f).

Function:     Displays information about one ore multiple disk devices. If no
              device name is specified, the current working directory's  disk
              will be used. The main advantage of DINFO over FREE is that  it
              displays disk spaces not only in terms of sectors but  also  in
              kilobytes and percentage of total disk capacity. Three options,
