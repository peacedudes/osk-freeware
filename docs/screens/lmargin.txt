    globe -- show the currently-lit face of the Earth in ASCII

        globe

    A cute ASCII graphic hack: it draws the Earth as it is lit right now,
    picked from thirty views spread across the day, so the globe turns from
    one run to the next as the hours pass.  It takes no options and prints
    one picture.

    The thirty views were made by Jef Poskanzer in 1994 from 256x256 bitmaps
    (originally from Sun) run through pbmtoascii.  Built here unchanged; the
    original sources are in SRC/globe/ORIG.
