INDEX -- what is on this disk, and where it came from
======================================================

Every command here runs with this disk mounted as /dd.  On your own OS-9
system that is a disk of its own named /dd and /h0, with your system on
/h1; DOC/README-RUNNING says how, and how to try it first under os9exec.

  *  A star before a name means that program uses one of Microware's
     runtime trap modules -- cio, and for some math or csl.  Those five
     modules are on this disk, in CMDS, included with Microware's
     permission (SOURCES.txt records the grant), so a starred program
     runs here like any other; the star tells you what it depends on.
     The grid at the foot of this file lists the starred programs, and
     its header carries the count.  A few names appear in more than one
     directory, so the grid holds slightly more files than names.

  Four programs are BASIC09 I-code: bio, blackjack, dedit and
  wysetime.  They are I-code modules (type 2, language 2) and need
  Microware's runb to interpret them, the way a starred program needs
  cio.  Run them by bare name with runb loaded -- `load runb` then
  `bio`.  Giving runb a pathname instead raises BASIC09 error 43,
  "Unknown procedure".  BASIC09's own codes are 10-80 and are not OS-9 error n
umbers.
