Usage: unzip [ -options[modifiers] ] file[.zip] [filespec...]
  -x  extract files (default)                -l  list files (short format)
  -c  extract files to stdout/screen (CRT)   -v  list files (verbose format)
  -f  freshen existing files, create none    -p  extract to pipe, no messages
  -u  update files, create if necessary      -t  test archive integrity
                                             -z  display archive comment
modifiers:
  -n  never overwrite existing files
  -o  overwrite files WITHOUT prompting      -a  convert text (CR LF => LF)
  -j  junk paths (don't make directories)    -U  don't make names lowercase
  -q  quiet mode (-qq => quieter)
