elvis

Captured while running.

collection was rebuilt trap-free (`-qm`) so it would run with nothing loaded
at all; most of the programs under CMDS need no module whatever.  The rest
were left as their authors built them.

A program that cannot find its trap handler stops at once with

    **** Can't install trap handler ****

That is the message to recognise.  It is not a broken program, and on this
disk you should never see it -- if you do, the five modules have been removed
or the execution directory is not this disk's CMDS.

The list was MEASURED, by running every program on a disk with the five
modules taken away and matching that message.  It was never derived from
looking for the string `cio` inside a binary: that proxy is wrong in both
directions, and this collection has the scars to prove it -- `vi_nocio`
contains the string and does not need the module, while `cyberwar`, `gnuchess`
and `g` lack it and do.

If you would rather use your own
--------------------------------

You run OS-9, so you have these modules already, and you may prefer your copy

cp, mv, rm, mkdir and dir are starred -- they are the GNU ones, and they
want cio like the other starred programs.  Under os9exec the emulator has
its own copy, move, rename and makdir, which need nothing loaded at all:

    os9exec -r icopy   <from> <to>
    os9exec -r imakdir <dir>
    os9exec -r move    <from> <to>
    os9exec -r rename  <old> <new>

Those are commands of the EMULATOR, not programs on the disk, so they are
typed where you start os9exec rather than at a shell prompt inside it.
On your own hardware the equivalents are the ones you already have: copy,
makdir, del, list and dir.

cio, csl and math now SHIP on this disk, with Microware's permission, so
the starred programs run too and nothing here is special.  DOC/README-CIO
has the detail.

The starred ones in DOC/INDEX use Microware's cio (see DOC/README-CIO).
They run: the module is here.

README-CIO -- the starred programs, and the five modules that serve them
=======================================================================

Some of the names in DOC/INDEX carry a star.  A star means the program needs
one of Microware's runtime trap modules: `cio` for nearly all of them, and
for some `math`, `math881`, `csl` or `csl020`.

THEY RUN HERE.  All five modules are on this disk, in CMDS, included with
Microware's permission -- SOURCES.txt records the exchange.  You need do
nothing, supply nothing, and fetch nothing.  The star tells you what a
program depends on, not what it lacks.

This file explains what the star means, and what to do in the two cases
where you might want a different arrangement.

Why so many programs need it
----------------------------

`cc -qixm` -- the C library in a shared trap handler rather than linked into
every binary -- was the normal way to build for OS-9, and it is why a starred
program is often a fraction of the size of a trap-free one.  Much of this
collection was rebuilt trap-free (`-qm`) so it would run with nothing loaded

vi_nocio

Captured while running.

=======================================================================

Some of the names in DOC/INDEX carry a star.  A star means the program needs
one of Microware's runtime trap modules: `cio` for nearly all of them, and
for some `math`, `math881`, `csl` or `csl020`.

THEY RUN HERE.  All five modules are on this disk, in CMDS, included with
Microware's permission -- SOURCES.txt records the exchange.  You need do
nothing, supply nothing, and fetch nothing.  The star tells you what a
program depends on, not what it lacks.

This file explains what the star means, and what to do in the two cases
where you might want a different arrangement.

Why so many programs need it
----------------------------

`cc -qixm` -- the C library in a shared trap handler rather than linked into
every binary -- was the normal way to build for OS-9, and it is why a starred
program is often a fraction of the size of a trap-free one.  Much of this
collection was rebuilt trap-free (`-qm`) so it would run with nothing loaded
at all; most of the programs under CMDS need no module whatever.  The rest
:q!
