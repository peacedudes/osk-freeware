$ trunc -?
OS-9/68k supplementary command.
Written by Carsten Emde; may be copied for non-commercial use.
Syntax: trunc <path> <num>
Function: reduce length of file <path> to <num>, where <num>
          specifies the new file length in decimal or optionally
          in hexadecimal when preceeded by '$' or '0x'.
Options: none
