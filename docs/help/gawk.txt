$ gawk -?
Syntax   : gawk [<opts>] <program-file> [<file>]
Function : pattern scanning and processing language
Options  :
   -a             use traditional syntax for regular expressions
   -e             use egrep syntax for regular expressions
   -f <file>      read program source from <file>
   -F <fs>        use <fs> for input field separator
   -v <var>=<val> assign <val> to variable <var>
   --             signal end of options
