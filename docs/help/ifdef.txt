$ ifdef -?
Syntax: ifdef [<opts>] [<file>] [<opts>]
Function: read C-source from <file> or stdin, remove #ifdefs and write
    to stdout.
Options:
    -t           print #define / #undef table
    -Dsymbol     define symbol
    -dsymbol     define symbol, can't be undefined
    -Usymbol     undefine symbol
    -Isymbol     ignore symbol
Adapted to OS-9/68k by Hubert Nehring
