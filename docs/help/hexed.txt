$ hexed -?
Syntax: hexed [<opts>] <path> {[<opts>] | [<path>]}
Function: dump, edit and retransform file(s) with binary data
Options:
     -t=<dir>       use <dir> for temporary files (default: '/r0')
     -e=<editor>    use <editor> as the texteditor (default: 'vi')
     -eo=<opts>     use editor-<opts> (default: '')
     -eg=<opts>     use editor-<opts> to go to specified line (default: '+')
     -?             show this message

Format for dumped lines as generated by 'hexed':
  bytecount         (optional) will not be interpreted by retransformation
  blank(s)          (at least one blank, obligatory) as separator
  hexdata bytes     (an arbitrary number) each of it consisting of one or two
                    hex-digits; the bytes are separated by blank(s)
  blank & ; & ASCII (optional) arbitrary comment or ASCII-representation

Alternatively the following line format can be retransformed:
  .a                inits ASCII-line
  blank(s)          (optional) as separator
  delimiter         arbitrary ASCII-character except blank as delimiter
  ASCII-data        text without delimiter
  delimiter & ASCII (optional, delimiter as defined above) arbitrary comment
