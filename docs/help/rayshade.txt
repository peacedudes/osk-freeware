$ rayshade -h
usage: rayshade [options] [filename]
Where options include:
	-A frame	(Begin with given frame #.)
	-C thresh	(Set adaptive ray tree cutoff value.)
	-D depth	(Set maximum ray tree depth.)
	-E eye_sep	(Set eye separation in stereo pairs.)
	-F freq		(Set frequency of status report.)
	-f 		(Flip all triangle normals.)
	-G gamma	(Use given gamma correction exponent.)
	-g 		(Use Gaussian pixel filter.)
	-h 		(Print this message.)
	-j 		(Toggle jittered sampling.)
	-l 		(Render image for left eye view.)
	-N number	(Render given number of frames.)
	-n 		(Do not render shadows.)
	-O outfile 	(Set output file name.)
	-o 		(Toggle opacity effect on shadowing.)
	-P cpp-args	(Options to pass to C pre-processor.
	-p 		(Preview-quality rendering.)
	-q 		(Run quietly.)
	-R xres yres	(Render at given resolution.)
	-r 		(Render image for right eye view.)
	-S samples	(Max density of samples^2 samples.)
	-s 		(Don't cache shadowing information.)
	-T r g b	(Set contrast threshold (0. - 1.).)
	-V filename 	(Write verbose output to filename.)
	-v 		(Verbose output.)
	-W x x y y 	(Render subwindow.)
	-X l r b t 	(Crop window.)
