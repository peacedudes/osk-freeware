$ diff_1.1 -?
Syntax   : diff [<options>] file1 file2
Function : generate differences of two files
Options  :
     -<num>      specify context size in decimal
     -a          treat all files as text files
     -b          ignore trailing whitespaces
     -B          ignore blank lines
     -c          generate context-style output
     -C          context-style and show name of last C function
     -d          don't discard lines (slow)
     -e          generate ed-script output
     -f          sorted ed-script
     -F <regexp> show previous line of match (only with -c)
     -H          use heuristics
     -i          ignore case
     -I <regexp> ignore lines matching regexp
     -l          paginate output through 'pr'
     -n          generate an reverse ed-script for RCS
     -N          suppress 'Only in <dir>'-messages
     -r          compare directories recursively
     -s          announce same files
     -S <fname>  (re-)start comparision of dirs with fname
     -t          expand tabs to spaces in output
     -T          use tabs in output
     -w          totally ignore spaces
  Adapted to OS-9/68k by Stephan Paschedag
