keep 1.0 -- OS-9 freeware collection

keep copies a program from this collection onto your own disk,
kept lists what keep has written, unkeep takes it back.

Usage: keep [-n] [-f] [-s] [-p <dir>] <program>...
       kept
       unkeep [-n] <program>...

  keep   copies the program and the data files DOC/DEPENDS says
         it reads, to the places it looks for them under /dd,
         and records every file it wrote.
  kept   lists every file keep has written, and the total.
  unkeep removes the files keep wrote for a program.  A file you
         have changed since -- a score, a saved game -- is left.

  -n     dry run: say what would happen, write nothing
  -f     overwrite a file that is already there
  -p <d> put everything under <d> instead of /dd
  -s     take the source tree too, where there is one
  -q     say nothing about files it left out (termcap, directories)

You need none of this if this collection is your /dd: everything
already runs where it is.  See DOC/README-RUNNING.
