$ travesty -H
travesty makes a travesty of its input.

travesty -A: print authorship notice
travesty -C: print copyright notice
travesty -H: print this notice
travesty -U: print short usage summary
travesty -V: print version number
travesty -W: print disclaimer of warranty

travesty [ -oord ] [ -nnum ] [ -rrand ] [ -sS ]: let the monkeys bang away
  -oord: use an order-ord Markov process (default 5, limit 20)
  -nnum: generate num output characters (default 0, meaning forever)
  -rrand: use rand as the random number generator seed (default based on time)
  -s: start output same as input
  -S: start output at a random spot in input (default)

travesty will respond to an ALRM signal by printing its random seed on stderr.
