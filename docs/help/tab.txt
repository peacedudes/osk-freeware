$ tab -?
Syntax: tab [<opts>]
Function: Pipe to format 68000 series assembler source code
Options:
     -a[=]<num> Argument field width (default 25)
     -b         Tabulate 6809 mnemonics instead of 68000
     -c         Only check conditionals
     -i[=]<num> Indent by <num> characters per level (default 5)
     -l[=]<num> Label field width (default 12)
     -m         Don't use bar (|) to mark indented lines
     -n         Ignore conditionals: no indent, no bar (overrides p)
     -o[=]<num> Opcode field width (default 10)
     -p         Form feed ($0c) on 'pag' nmemonics
     -r         Remove all unnecessary spaces and tabs (overrides s)
     -s         Format for columns 13,25,46 (overrides a,l,o)
     -u         Allow only uncommented lines
     -?         List usage
