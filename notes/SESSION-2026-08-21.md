## Commits, in order

1. **`make_overlay.sh`** -- the clean `/dd` overlay every rebuild needs had
   gone missing. `tools/rebuild/README.md` listed it under "Prerequisites,
   none of which are in this repo", so it was somebody's local directory and
   it was not there any more; the whole rebuild machinery was unusable. Worked
   out again from the README and written down. Includes why a copy and not
   symlinks: os9exec will not open a symlink through its host-directory RBF
   emulation, and the failure arrives on a `#` line where the usual
   `grep -v '^# '` hides it completely.

2. **The pdksh OSK port, recovered.** `osklib.r` was never a missing file --
   it is a build product, `merge`d from 21 objects, and its sources were in
   the pool the whole time. The import into `disk/SRC/pdksh/` had dropped the
   port's entire `OSK/` directory except `OSK/INCL`, so the shipped source
   could not be built by anyone. 52 files restored, two headers refused as
   Microware's. `osklib.r` built: 21 sections, 11 KB. Full recipe and the one
   remaining bug in `tools/rebuild/pdksh/README.md`.

3. **`/dd`, not `/h0`** -- `tools/measure_layout.py` and
   `notes/DECISION-placement.md`. 258 programs want the collection at `/dd`
   against 53 that want data at `/h0`. Demonstrated as well as counted.

4. **Every stale count corrected**, and `README-CIO` rewritten. It still told
   people to go and fetch `cio`, months after the five modules started
   shipping by Microware's permission.

5. **`keep`, `drop`, `kept`** as OS-9 modules, `SRC/keep/keep.c`.

6. **`msfm` removed** -- Microware's proprietary source, on the shipping disk.
   Plus a ninth `check_disk` rule so it cannot happen again.

7. **`SRC/uucpbb`** -- 114 files. `DOC/ORIGINS` had cited it for 18 programs
   since they were added, and its header promises the source of every program
   is on the disk. There was no such tree.

8. **`extract_pool.py` fixed** -- it silently dropped 16 pool files, and had
   done since it was written. Recovered the `sox` and `msntp` manuals.

9. **`dedit`** -- a reversal decided on 2026-08-15 and never carried out.

10. **`zoo 2.1`** as a REBUILT alternate.

11. **The catalogue became the chooser** the keep/drop plan asked for: a `+`
    on every program and a tray that builds `keep a b c` to paste. Verified by
    running the page's own JavaScript headless under node with a stub DOM —
    it parses, builds the command, totals the sizes, and renders the button.

12. **`screen_microware.py` now says WHICH SDK a match came from.** `paths.SDK`
    is a working build overlay carrying this collection's own `ncurses.l`,
    `libgcc.l` and `os9unix/` headers; matches against those were reported
    identically to matches against Microware's own files. Over `disk/LIB` it
    flagged 113 files, nearly all self-matches — a screen that cries wolf is
    one people stop reading.

    **It immediately corrected a decision of mine.** I had refused two pdksh
    headers, `ioctl.h` and `termios.h`, as Microware's. Neither `ioctl.h` nor
    `termio.h` exists in the pristine SDK at all, and no copy carries a
    Microware notice — they are the standard System V definitions, and any two
    expressions of that interface overlap. Both restored.

13. **The public `README.md` recommended the arrangement the measurement says
    is worst**, and put its cost at "20 programs" where it is 258. Rewritten,
    along with its counts (612 → 604/942, ~125 MB → ~195 MB, 363 → 522
    commands) and its claim that `cio` is not here — it has shipped by
    permission since 2026-08-16.

14. **The no-Microware release check, run and passed.** `notes/RELINK-CIO.md`
    says to prove the image still builds with the five permitted modules
    removed, because anything the BUILD itself runs must stay trap-free --
    that is how a relinked `tar` broke the build once. Copied the tree,
    deleted `cio`, `csl`, `csl020`, `math`, `math881`, and built:
    **7503/7503 files extracted** by the collection's own `tar`. The build
    still needs no Microware software at all.

    Running programs against that image also **validates the star list from
    the other direction**: `cat` and `basename` are starred and refuse with
    `**** Can't install trap handler ****`; `wc`, `arc` and the new `kept` are
    unstarred and run. So the new `keep`/`drop`/`kept` really are trap-free,
    which was the point of building them with `-qm`.

    Doing this also found a bug in the check I had just added: the
    `screened-src.txt` allowlist matched on literal `disk/...` paths, so it
    failed against any tree not called `disk` -- including the copy this very
    check builds. Now compared relative to the tree root.

## Findings that cost the most to establish

**The bash `keep` failed in the only case `keep` exists for.** Three bash
scripts were already on the disk, documented in `DOC/INDEX` and
`DOC/README-KEEP` -- and I overwrote them before checking, which was careless
and is why the restore is in the history. Restored, then tested: run against a
`/dd` that is not the collection, the script version needs `bash` and
`/dd/tmp` ON THE DESTINATION, has neither, copies nothing, and says almost
nothing about why. Its own header assumes the collection lives on `/h0`, which
is the premise the measurement overturned. That is why it was replaced rather
than repaired. The originals are kept as `SRC/keep/*.sh`.

**`cpp` aborts on `tree.c` with no diagnostic at all.** `os9unix/varargs.h`
expands its `type` argument seven times inside a nested `?:`; two `va_arg`s on
one line, one with the two-token type `unsigned int`, kills the preprocessor
outright -- `E_PRCABT`, a register dump, and nothing else. Bisected by
truncating the file.

**A `>` redirect in the OS-9 shell will not overwrite** (`E_CEF`, 218). A
rebuild that appears to succeed can leave you measuring the previous file.
This produced one wrong "21 sections" report here before it was caught.

**zsh does not word-split unquoted variables.** A `for f in $LIST` loop in a
build driver ran exactly once, with the whole list as one filename, and `cc`
answered `no recognized suffix`. Use an array.

## The rule this session kept proving

Make every check fail once before believing it. Done deliberately for the new
Microware screen (put an `msfm` file back, watched it fire) and for the
overlay's stamp guard. Not done for `merge`, and a stale `osklib.r` was
reported as fresh; not done for the first `keep` build, and a `grep` matched
the login banner instead of the program's output.
