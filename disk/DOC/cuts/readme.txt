This is the 1.5 release of the CUTS source code.This file contains a brief history of the program, instructions forcompiling CUTS, and a list of files in the archive.Brief history:The CUTS format was designed by me at the request of Eric Tileniusto provide a method for transferring CoCo and OS9 binaries overelectronic mail.  As far as our testing can show, CUTS-encodedfiles are resistant to character losses due to:  ASCII <-> EBCDICconversion (which can trash uuencoded files) and  mailers whichstrip leading/trailing spaces or barf on lines longer than 80characters.The C implementation was originally the work of Simmule Turner(simmy@nu.cs.fsu.edu).  The VMS parts were added by Eddie Kuns(ekuns@zodiac.rutgers.edu), with some additional contributionsby Claude Morin (claude%deepthot.uwo.ca@cornellc.ccs.cornell.edu).I took over the maintenance in October, 1988.  I split the sourceand fixed some problems.  Then, Eddie Kuns re-worked much of thecode in February, 1989 to get it working robustly under VMS, aswell as cleaning up some of the logic and shortening the code.Any changes, fixes, or alterations to this source should be forwardedto me via Email at one of the following addresses:Internet: koonce@math.berkeley.eduBitnet:   koonce@UCBBRAHMSUUCP:    ...!ucbvax!math!koonceDelphi:  TIMKOONCECompuServe: 72276,1135In particular, I would like to know about any changes needed toport CUTS to other systems.                                        Tim Koonce                                        March 06, 1989To compile cuts for:OS9 --  You must have the Kreider C-library.      If you have 'make', then compile with 'make -f makefile_os9'.      Otherwise, you can use the following command line:cc  -dOS9 -f=cuts cuts.c cuts_decode.c cuts_encode.c cuts_getopt.cUnix -- 'make -f makefile_unix'VMS -- read instructions in file 'makefile_vms.com'.This archive contains:ReadMe.txt         - this text filecuts.c             - main programcuts.man           - man pagecuts.h             - header filecuts_encode.c      - encode-specific subroutinescuts_decode.c      - decode-specific routinescuts_getopt.c      - a PD 'getopt()' implementationmakefile_os9       - makefile for OS9/6809 Tandy 'make'makefile_unix      - makefile for Unix 'make'makefile_vms.com   - command file to create cuts for VAX/VMS
