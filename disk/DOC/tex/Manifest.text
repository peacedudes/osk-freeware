    The archives are archived with LHa 2.01, as ported to OSK byMike Haaland.==============================================================================               DESCRIPTION OF EACH FILE    About_Latex.tex   - This text file is the LaTeX source code of anarticle describing the OS9/TeX system.  It is intended to both describethe system to those unfamiliar with TeX, explain some of the parts ofthe OS9/TeX system, and serve as an example LaTeX document.  If you areunfamiliar with TeX, or if you have never dealt with the various piecesof a complete TeX system, this may help explain things.    Manifest.text  - This file explains what each file is.    Installation.text - This file explains how to build a TeX systemfrom the archives and create the installation files. Read thiscarefully, as the correct operation of the system depends on havingcertain directories correctly setup, and on having the installationfiles properly compiled.    Usage.text        - This file explains how to use the variousprograms supplied.  Before you can print anything out, you will need toread this carefully to learn how to create the necessary fonts. Becauseall the fonts can be created using MetaFont, they are not included inany of the archives.  Since this is a fairly dense document, I suggestyou print it out and read it carefully.  If you don't have a printer,you shouldn't be downloading a typesetting system.    TeXcmds.lzh       - The executable files for TeX, MetaFont, BibTeX,and a number of utility programs.  750k archive.    DviTranslators.lzh  - Programs to convert DVI output files for aparticular printer.  Ten different printers are currently supported:dvialw (Apple LaserWriter and other PostScript printers), dvidjp (HPDeskJet Plus), dvieps (9-pin Epson printers at 240 x 216 dpi), dviimp(Imagen imPRESS Laser printers), dvijet (HP LaserJet), dvijep (HPLaserJet Plus), dvilj2 (HP LaserJet 2), dvimac (Apple Imagewriter at 144dpi), dvioki (Okidata 192 at 144 dpi), dvitos (Toshiba P-1351 at 180dpi).  Based on the Beebe family of printer drivers.  300k archive.    TeXDir.lzh    - The various files needed by the TeX system. This archive contains all of the files needed to install and use the TeXsystem (4 meg uncompressed).  Do NOT attempt to dearchive this beforeyou've read the Installation instructions, lest you end up with 700+files in the wrong places.  1.4meg archive.    tangleweave.lzh  - Tangle and Weave are parts of Knuth's "WeB"system for literate programming.  These will only be of interest to afew people.==============================================================================End Notes: 1)  This system was ported to OS9/68k by Tim Kientzle from the Unix TeXdistribution.
