PVIC 1.0a=========This distribution has been tested only under OS-9 v2.4.The executables in the CMDS directory were compiled with Microware C 3.2:vi		requires the cio trap module. Use this version if you have a cio		module that is compatible with the v2.4 cio module.vi_cio 	does not use a trap module. Use this version if you do not have		cio or have an incompatible version. In this case you should rename		'vi' to 'vi_cio' and 'vi_nocio' to 'vi'.See the document vi.txt for other installation details.PVIC contains summary help screens, accessed by the ':help' colon command.Read any good Unix user guide for extra documentation on using vi.If you are running a version of OS-9 other than 2.3 or 2.4, in other wordsyour system requires csl in place of cio or needs a different version ofcio, you may need to recompile vi before use unless you want to use thefully linked version.Many thanks to Frits Wiarda, who did all the really hard work and produceda good, stable editor with excellent screen handling from Stevie. See thedocument 'vi.txt' for Frits' contact details and his description of hishard work.Martin Gregoriegregorie@logica.com10 June 1998
