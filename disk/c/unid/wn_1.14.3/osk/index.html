Served by OS-9

This page is being served by WN 1.14.3, John Franks' web server, compiled for OS-9/68000 and running under os9exec. The server is from 1996.

The document root is /h0/c/unid/wn_1.14.3/osk -- a path compiled into the binary by whoever ported it, pointing at their own source directory. This collection is mounted as /h0, so the path resolves.

What else is on this disk

  • 519 programs, all of which run with nothing else present
  • TeX, LaTeX and MetaFont, with working formats
  • Elm and UUCP for mail, ADL for writing text adventures
  • Ghostscript 3.33, netpbm, three vi editors and two Emacsen
